# Computah Vision Project

This is a computer vision project part of the course Computer Vision offered at CAIRO.thws by Prof. Dr. Dominik Seuß. It consists of two assignments with multiple sub-parts each.

The assignment description can be found at [in a PDF file](Common/CV%20-%20Sheet%201%20Portfolio.pdf). The dataset in question can be found in the [same folder](Common/GarbageDataset/GarbageDataset/).


---


## Assignment 1

The goal of the assignment was to fine-tune a YOLO model for obtaining a garbage sorting algorithm with computer vision.

The assignment entailed the following steps:
- Analysis of the dataset
- Processing and augmentation of a dataset.
- Use of best practices in Python programming and computer vision
- Model training and evaluation, namely YOLO26m
- Visualisation and error analysis


---


## Assignment 2

The goal of the assignment was to explore how Deep Metric Learning can improve waste detection and sorting by identifying similarities and differences between waste objects.

The assignment entailed the following steps:
- Analysis of the waste dataset and its categories.
- Selection of a suitable learning approach.
- Design of a strategy for selecting training samples.
- Development of a theoretical approach for grouping similar waste objects.
- Analysis and visualisation of the resulting embedding space.
- Evaluation of how well the approach can identify and distinguish waste categories.
Note: The assignment focused on theoretical concepts and methods, without implementing or training a model.
